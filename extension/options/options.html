Privacy & permissions

Tabcove saves the web address, page title, and save time of the tabs you choose to stow. That stays on this device: it sends nothing, and contains no network code at all. Here is every permission it asks for, and why.

Permission What it is used for
tabs Read the title and address of your open tabs so they can be saved, and close them when you ask.
tabGroups Read and rebuild Chrome tab groups so a saved group keeps its name and colour.
storage Keep your library on this device.
unlimitedStorage Lift Chrome's 10 MB extension cap so a large library keeps working instead of silently failing to save.
contextMenus Add the right-click "Stow" actions.
favicon Show site icons from Chrome's local cache. This permission exists so Tabcove never has to ask a remote favicon service for your addresses.
alarms Sweep the undo bin and check whether a backup is due. Chrome shuts extensions down when idle, so a timer is not an option.
No host permissions. Tabcove cannot read, change, or even see the contents of any web page. It has no content scripts and no access to the network.
